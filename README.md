# Datalent Solutions Web Page

Este proyecto es una aplicación Angular 20 optimizada para SEO y ciberseguridad, siguiendo el plan estratégico de posicionamiento web.

## Características principales
- SEO técnico avanzado: meta tags, sitemap.xml, robots.txt, Schema.org
- Seguridad: CSP, validación de formularios, headers recomendados
- Accesibilidad y rendimiento: diseño responsive, lazy loading, optimización de recursos
- Cumplimiento legal: enlaces a políticas de privacidad y cookies

## Requisitos
- Node.js 18+
- Angular CLI 20

## Instalación
```bash
npm install
```

## Desarrollo
```bash
npm start
```

## Producción
```bash
npm run build:prod
```

## Seguridad recomendada para despliegue
- Forzar HTTPS y HSTS en el servidor web
- Servir con headers HTTP seguros (CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy)
- Mantener dependencias actualizadas

## SEO
- Sitemap y robots.txt incluidos
- Metaetiquetas y Schema.org en index.html
